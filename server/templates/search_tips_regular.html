Be specific. The more relevant words you use, the better the results.

Use quotes to search for a phrase, for example "exact phrase".

Restricting a search to one field

By default every field of a item is searched. Prefix a term with a field name to search only that field.

  • Where the text contains a phrase
    body_html:"some phrase"
  • Where the headline contains one of two words
    headline:(first OR second)
  • Where the slugline starts with a code
    slugline:ABC*

Searching by taxonomy

Topic, region and wire service are stored as coded values. Search them by code, which is stable and does not change when a label is reworded.

  • Everything tagged International wire
    subject.code:international
  • International wire and Politics
    subject.code:international AND subject.code:politics

You can search by label instead, but a label with a space has to be quoted: subject.name:"Conflict and security".

For anything more than a quick lookup, use the filter panel on the left. Its filters are exact and they can be saved as a topic.

Wildcards

Use ? for a single character and * for zero or more.

Proximity

Use ~ to find terms within n words of each other: "first second"~10.

Using + and - for what must and must not appear

first second +must -never

Filters in the {{ config.WIRE_SECTION }}

  • Topic
  • Region
  • Wire service
  • Published date, a single date or a range

Save any combination of filters and search terms as a topic to get an alert when a new item matches it, immediately or as a daily digest.
