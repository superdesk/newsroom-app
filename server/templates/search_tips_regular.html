Be specific. The more relevant words you use, the better the results.

Broad = port strike
Specific = Gdansk port strike container terminal

Use quotes to search for a phrase.

Loose = road closure
Exact phrase = "road closure"

Restricting a search to one field

By default every field of a report is searched. Prefix a term with a field name to search only that field.

  • Where the assessment contains the exact phrase "secondary road"
    body_html:"secondary road"
  • Where the title contains strike or blockade
    headline:(strike OR blockade)
  • Where the reference contains a case code
    slugline:EU-LOG-114

Searching by taxonomy

Severity, threat type, region, country, sector and TLP marking are stored as coded values. Search them by code, which is stable and does not change when a label is reworded.

  • Everything tagged Europe
    subject.code:europe
  • Critical severity in the logistics sector
    subject.code:critical AND subject.code:logistics
  • Poland or Czechia
    subject.code:pl OR subject.code:cz

You can search by label instead, but a label with a space has to be quoted: subject.name:"Civil unrest".

For anything more than a quick lookup, use the filter panel on the left. Its filters are exact and they can be saved as a watch.

Wildcards

Use ? for a single character and * for zero or more: block* Gda?sk

Proximity

Use ~ to find terms within n words of each other. "port closure"~10 finds port and closure within ten words of each other, in either order.

Using + and - for what must and must not appear

strike blockade +warsaw -rail

  • warsaw must be present
  • rail must not be present
  • strike and blockade are optional

Filters in the {{ config.WIRE_SECTION }}

  • Severity
  • Threat type
  • Region
  • Country
  • Sector
  • TLP marking
  • Released date, a single date or a range

Save any combination of filters and search terms as a watch to get an alert when a new report matches it, immediately or as a daily digest.
